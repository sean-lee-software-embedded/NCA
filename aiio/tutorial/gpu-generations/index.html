2. A100：Ampere

最重要：TF32

A100 的 Tensor Core 讓 TF32 成為 AI Training 的重要格式之一。考題看到「Ampere」「TF32」時，優先想到 A100。

最重要：MIG

A100 已支援 Multi-Instance GPU，可把一張 GPU 隔離成多個 GPU instance。MIG 不是 H100 才出現。

A100
├─ Architecture : Ampere
├─ HBM          : 40GB / 80GB
├─ MIG          : Yes
├─ 最大 MIG      : up to 7 instances
└─ Exam keyword : TF32 / MIG
陷阱：A100 = Ampere，不要被 NVIDIA 的 Ada Lovelace 架構名稱干擾。A100 的 A 不是 Ada。

3. H100：Hopper

Transformer Engine

針對 Transformer workload 動態運用較低精度格式，提高 AI 訓練與推論效率。

FP8

Hopper 世代的代表關鍵字。考試常把 FP8 和 H100 / Transformer Engine 配在一起。

NVLink 4

H100/H200 的高速 GPU-to-GPU scale-up 互連重點。

H100
├─ Hopper
├─ 4th Gen Tensor Core
├─ Transformer Engine
├─ FP8
├─ HBM3
├─ NVLink 4
└─ MIG
Infrastructure 思維：H100 不是完整 Server。H100 = GPU；HGX H100 = GPU platform；DGX H100 = NVIDIA 完整系統。

4. H200：不是新架構，而是 Hopper + 更強 Memory

141 GB

HBM3e capacity

4.8 TB/s

Memory bandwidth

H200 最適合用來理解「AI 不只吃算力，也吃記憶體」。LLM inference、KV Cache、long context、memory-bound workload 都會受 Memory capacity 與 bandwidth 影響。

H100 → H200
Compute architecture : Hopper → Hopper
核心變化             : Memory capacity / bandwidth ↑
陷阱：看到 H200 不要選「Blackwell」。H100 和 H200 都屬於 Hopper。

5. B200：Blackwell

Blackwell

從 Hopper 進入新 GPU architecture 世代。

FP4

Blackwell 進一步強化低精度 AI 計算，特別適合高效率 GenAI inference。

180GB HBM3e

更大的 GPU memory，支援更大型模型與更高 inference concurrency。

A100TF32 / FP16
H100FP8
B200FP4
B300FP4 + Reasoning
RubinNVFP4 + HBM4
低精度 ≠ 永遠比較好。 越低 precision 通常能提高 throughput、降低 memory footprint，但仍要維持可接受的 model accuracy。

6. B300：Blackwell Ultra

B300 的考點不是「又換了一個完全不同的 architecture」，而是：

B300 = Blackwell Ultra = Blackwell 的強化版
比較B200B300

Reasoning model、long context 與大量 concurrent users 會讓 KV Cache 快速吃掉 GPU memory。B300 的大容量 HBM3e 正是為這類 workload 強化。

7. Rubin：2026 最新主線

截至 2026 年 8 月，NVIDIA 官方已宣布 Vera Rubin 正在進入 full production。Rubin 是 Blackwell / Blackwell Ultra 之後的新一代 GPU architecture。

9. NVLink、NVSwitch、InfiniBand：Scale-up vs Scale-out

Scale-up

GPU ↔ GPU 在單機或 rack-scale fabric 內高速互連。

NVLinkNVSwitch

Scale-out

Server / Node ↔ Server / Node 擴大整個 AI cluster。

InfiniBandSpectrum-X Ethernet

NVLink / NVSwitch → Scale-up ｜ InfiniBand / Ethernet → Scale-out
陷阱：NVLink 不是 InfiniBand。NVLink 是 GPU fabric；InfiniBand / Ethernet 是 cluster networking。

10. MIG：考試常見的 GPU Partitioning

MIG = Multi-Instance GPU。它讓一張支援 MIG 的實體 GPU 切成多個隔離 instance，讓不同 workload 更容易共享 GPU。

Physical GPU
├─ MIG Instance 0
├─ MIG Instance 1
├─ MIG Instance 2
└─ ...
指令陷阱：sudo nvidia-smi -i 0 -mig 1 的 1 是「Enable」，不是「建立一個 instance」。
# Enable MIG
sudo nvidia-smi -i 0 -mig 1

# 例：H100 80GB 建立 5 個 1g.10gb GI 並建立 CI
sudo nvidia-smi mig -i 0 \
  -cgi 1g.10gb,1g.10gb,1g.10gb,1g.10gb,1g.10gb \
  -C

# 確認
nvidia-smi -L
sudo nvidia-smi mig -lgi
sudo nvidia-smi mig -lci

為什麼 H100 1g.10gb 最多是 7 個？

快速模型：H100 MIG 可以把 Compute 想成 7 份、Memory 想成 8 份。最大 instance 數看「哪種資源先耗盡」。

1g.10gb:
Compute → floor(7 / 1) = 7
Memory  → floor(8 / 1) = 8
Max     → min(7, 8) = 7
注意：這是理解普通 MIG profile 的快速模型。實際合法配置還要受 NVIDIA 定義的 profile、placement 與額外 engine resource 限制。

14. NCA-AIIO 模擬題

以下是依官方 Blueprint 設計的練習題，不是正式考題。

Q1. Which GPU is based on NVIDIA Ampere architecture?

A. H100　B. A100　C. B200　D. Rubin

看答案

B. A100。 A100 = Ampere。

Q2. Which feature partitions one physical GPU into isolated GPU instances?

A. NVLink　B. MIG　C. InfiniBand　D. TensorRT

看答案

B. MIG。

Q3. Which statement about H200 is correct?

A. It is Blackwell.　B. It is Hopper with more/faster HBM than H100.　C. It is a DPU.　D. It replaces CUDA.

看答案

B。 H100、H200 都是 Hopper。

Q4. Which GPU family introduced FP8 + Transformer Engine as a major feature?

A. A100　B. H100　C. B300　D. BlueField

看答案

B. H100 / Hopper。

Q5. B300 is best described as:

A. Hopper Ultra　B. Blackwell Ultra　C. Rubin Ultra　D. Ampere Ultra

看答案

B. Blackwell Ultra。

Q6. A reasoning workload uses long context and a large KV cache. Which hardware characteristics become especially important?

A. Display outputs　B. GPU memory capacity and bandwidth　C. USB ports　D. CPU fan count

看答案

B。 KV Cache 直接吃 GPU memory，長 context / 高 concurrency 也會增加 memory pressure。

Q7. Which technology is primarily used for high-bandwidth GPU-to-GPU scale-up communication?

A. SATA　B. NVLink　C. IPMI　D. USB

看答案

B. NVLink。

Q8. Which technology is more associated with node-to-node scale-out networking?

A. NVLink only　B. InfiniBand / Ethernet　C. HBM　D. MIG

看答案

B。

Q9. Which NVIDIA tool is specifically designed for data center GPU monitoring and management?

A. TensorRT　B. DCGM　C. CUDA compiler　D. NVSwitch

看答案

B. DCGM。

Q10. What is BlueField?

A. GPU architecture　B. DPU　C. HBM technology　D. CUDA library

看答案

B. DPU。

Q11. What does nvidia-smi -i 0 -mig 1 do?

A. Creates one MIG instance　B. Enables MIG mode on GPU 0　C. Creates 7 MIG instances　D. Sets GPU index to 1

看答案

B。 1 = enable，不是 instance count。

Q12. Which statement is correct?

A. B200 is a complete DGX server.　B. DGX B200 and B200 mean exactly the same thing.　C. B200 is a GPU; DGX B200 is a complete NVIDIA system.　D. HGX is a GPU precision format.

看答案

C。
