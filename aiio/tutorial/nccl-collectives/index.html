CUDA / NCCL / DISTRIBUTED TRAINING

CUDA、NCCL 與 Collective Communication 一次分清

NCA-AIIO 很容易把 CUDA、cuDNN、NCCL、TensorFlow / PyTorch 放在同一題裡。最有效的方式不是背縮寫，而是先問：這題在考「GPU 怎麼算」、「神經網路怎麼算得快」，還是「GPU 彼此怎麼溝通」？

CUDA = GPU 怎麼算　｜　cuDNN = Neural Network 怎麼算得快　｜　NCCL = GPU 之間怎麼溝通

CUDA

GPU parallel computing platform / programming model。

看到 parallel computing、GPU programming、multi-GPU execution，先想到 CUDA。

cuDNN

Deep Neural Network primitives。

Convolution、activation、normalization 等 DNN 運算的高度最佳化函式庫。

NCCL

Collective Communication。

AllReduce、AllGather、Broadcast、ReduceScatter 等 GPU-to-GPU 通訊。

2. Collective Communication 到底是什麼？

Collective Communication 的意思是：不是只有兩個 process / GPU 在傳資料，而是一群 GPU 一起參與同一個通訊操作。

考試抓法：看到 AllReduce、AllGather、Broadcast、ReduceScatter、gradient synchronization，優先聯想到 NCCL。
Operation核心意思一句話記法
Broadcast一個 root GPU 的完整資料傳給所有 GPUOne → All
ScatterRoot 的完整資料切開後分給大家One → Pieces
Gather大家各自的資料收集到一個 rootPieces → One
AllGather大家各有一份，最後每個人都拿到全部Pieces → All
Reduce大家的資料做 SUM/MAX 等合併，結果只給 rootCombine → One
AllReduce大家資料先合併，完整結果再給所有 GPUCombine → All
ReduceScatter大家資料先合併，再把結果切開分給各 GPUCombine → Pieces

3. Broadcast：一個人發給所有人

Before:
GPU0 : A     ← root
GPU1 :
GPU2 :
GPU3 :

Broadcast
    ↓

After:
GPU0 : A
GPU1 : A
GPU2 : A
GPU3 : A
KEYWORDOne → All。例如 root rank 將初始化參數、configuration 或同一份資料發給其他 GPU。

4. AllGather：每人一片，最後人人都有完整拼圖

Before:
GPU0 : A
GPU1 : B
GPU2 : C
GPU3 : D

AllGather
    ↓

After:
GPU0 : A B C D
GPU1 : A B C D
GPU2 : A B C D
GPU3 : A B C D
AllGather 沒有做 SUM。它只是把每個 GPU 的不同資料片段「收齊」，然後完整複製給所有 GPU。

5. AllReduce：Distributed Training 最常考

假設四張 GPU 各自算出不同 gradient：

GPU0 gradient = 1
GPU1 gradient = 2
GPU2 gradient = 3
GPU3 gradient = 4

AllReduce(SUM)
      ↓
1 + 2 + 3 + 4 = 10
      ↓
GPU0 : 10
GPU1 : 10
GPU2 : 10
GPU3 : 10
為什麼 Training 要用？ Data Parallel Training 時，每張 GPU 處理不同 batch，因此算出的 gradient 不同；更新 model weights 前需要先同步 gradient。
GPU0 → Batch A → gradient A ─┐
GPU1 → Batch B → gradient B ─┤
GPU2 → Batch C → gradient C ─┼→ NCCL AllReduce → synchronized gradient → update weights
GPU3 → Batch D → gradient D ─┘
Gradient synchronization → AllReduce → NCCL

6. ReduceScatter：先合併，再分片

GPU0 : [1,    2,    3,    4]
GPU1 : [10,   20,   30,   40]
GPU2 : [100,  200,  300,  400]
GPU3 : [1000, 2000, 3000, 4000]

          Reduce (SUM)
               ↓
      [1111, 2222, 3333, 4444]
               ↓
             Scatter
               ↓
GPU0 : 1111
GPU1 : 2222
GPU2 : 3333
GPU3 : 4444
最容易跟 AllReduce 混：AllReduce 讓每個 GPU 拿到「完整合併結果」；ReduceScatter 則讓每個 GPU 只拿到「合併結果的一部分」。

8. Q24：為什麼答案是 CUDA？

題型：Which parallel computing platform enables programming in popular languages with parallelism extensions?

答案：CUDA。題目問的是「parallel computing platform / programming model」，不是特定資料分析 library。

選項定位
CUDA通用 GPU parallel computing platform / programming model
cuDFGPU DataFrame / tabular processing
cuMLGPU-accelerated machine learning
cuGraphGPU-accelerated graph analytics
記法：CUDA 是「地基」；cuDF / cuML / cuGraph 是建立在 GPU 加速生態上的專用工具。

9. Q25：CUDA vs NCCL 為什麼會有歧義？

題型：Which component of the AI software ecosystem manages the distribution of deep learning model training across multiple GPUs?

這份題庫的預期答案是 CUDA。它把「training workload 分配到 multiple GPUs」歸類為 CUDA 的 multi-GPU computing / programming 能力。

選 CUDA 的關鍵字

parallel computing platform、GPU programming、multi-GPU execution、distribute computation across GPUs。

選 NCCL 的關鍵字

collective communication、GPU-to-GPU communication、AllReduce、AllGather、Broadcast、gradient synchronization。

重要：若題目明確問「GPU 之間如何同步 gradient / collective communication」，答案應是 NCCL；若像這份題庫使用較廣義的「distribution of training across multiple GPUs」，它把答案定為 CUDA。

11. 延伸題

Q1. A distributed training job needs to synchronize gradients across eight GPUs. Which operation is most relevant?
A. Broadcast　B. AllReduce　C. Gather　D. Scatter
答案

B. AllReduce。先合併各 GPU gradient，再讓所有 GPU 得到同步結果。

Q2. Which NVIDIA library implements optimized collective communication for multiple GPUs?
A. cuDF　B. cuDNN　C. NCCL　D. OpenSM
答案

C. NCCL。

Q3. GPU0 owns model parameters that must be copied unchanged to every GPU. Which collective is the best match?
A. Broadcast　B. ReduceScatter　C. Reduce　D. Gather
答案

A. Broadcast。One → All。

Q4. Four GPUs each hold one shard, and every GPU needs the complete set of four shards. Which operation?
A. AllGather　B. AllReduce　C. Scatter　D. Reduce
答案

A. AllGather。Pieces → All，而且不需要做 SUM。

Q5. Which platform is the foundation for general-purpose NVIDIA GPU parallel programming?
A. NCCL　B. CUDA　C. cuGraph　D. Triton
答案

B. CUDA。

Q6. Which library is most directly associated with convolution and deep-neural-network primitives?
A. cuDNN　B. NCCL　C. cuDF　D. OpenSM
答案

A. cuDNN。

Q7. After a reduction, each GPU should receive only one shard of the combined result. Which operation?
A. AllReduce　B. Broadcast　C. ReduceScatter　D. AllGather
答案

C. ReduceScatter。

Q8. Which phrase most strongly indicates NCCL rather than CUDA?
A. Parallel computing platform　B. GPU programming model　C. Collective communication　D. C/C++ extensions
答案

C. Collective communication。
