ML / DATA ANALYSIS FUNDAMENTALS

Regression、F1、Heatmap、Box Plot 到底差在哪？

不要把它們背成一堆名詞。先判斷題目在問哪一層：預測、訓練、評分、畫圖，還是找原因。層級一分清，很多選項會自動排除。

① Task 任務預測什麼？
Regression / Classification
② Training 訓練模型怎麼學？
Learning Rate / Batch Size
③ Metrics 評分模型好不好？
MAE / R² / F1
④ Visualization結果長怎樣？
Heatmap / Box Plot
⑤ Statistics誰真的有影響？
Regression / t-test / ANOVA
考試先問自己：這題到底要我「預測、訓練、評分、畫圖，還是找原因」？

怎麼讀這張圖：Task 是「做什麼預測」；Training 是「怎麼訓練」；Metrics 是「模型表現如何」；Analysis 是「哪些因素真的有影響」；Visualization 則只是「把資料畫出來讓人看懂」。

最重要的分界：
Regression / Classification 是 Task；MAE / R² / F1 是 Metrics；Learning Rate / Batch Size 是 Training settings；Heatmap / Box Plot 是 Visualization；t-test / ANOVA / Regression Analysis 是 Statistical Analysis。

1. Task：先看「答案長什麼樣」

Regression：預測數字

GPU / Batch / Model Size→72.5 分鐘

輸出是連續數值。例：房價、溫度、功耗、Latency、Training Time。

Classification：預測類別

GPU telemetry→Normal / Fault

輸出是 class / label。例：Cat / Dog、Spam / Not Spam、Normal / Error。

口訣：答案是一個數字 → Regression；答案是在選類別 → Classification。

2. Training：Learning Rate / Batch Size 是訓練旋鈕

名詞直覺常見影響
Learning Rate每一步要改多少，像「步伐大小」太小學得慢；太大可能跳過最佳點、難收斂
Batch Size一次拿多少筆資料計算大 batch 通常需要更多 GPU memory
Epoch整份訓練資料看幾遍太少可能 underfit；太多可能 overfit
陷阱：題目若問「模型最終 performance 的統計指標」，Learning Rate / Batch Size 不是成績，它們是 hyperparameters。

3. Metrics：模型的「成績單」

Regression → MAE / RMSE / R²

實際 Training Time預測錯多少
100955

MAE

平均錯多少。

(5 + 4 + 3) / 3 = 4 分鐘

越小通常越好，而且單位和原始目標一樣。

R²

模型能解釋資料變化到什麼程度。

考試看到 regression model evaluation，R² 是典型選項。

Classification → Accuracy / Precision / Recall / F1

F1 的直覺：綜合 Precision 與 Recall。當你不想只看整體猜對率，而且在意 false positive / false negative 的平衡時，F1 很常用。
Cross-Entropy Loss：常用於 Classification 的訓練 loss。它告訴模型「這次錯得多嚴重」，供 training 更新權重；F1 則常拿來評估分類結果。
題目字眼優先想到
continuous numeric value / regressionMAE、MSE、RMSE、R²
class / label / classificationAccuracy、Precision、Recall、F1

5. Statistical Analysis：誰「真的」有影響？

看到 significant effect / impact / statistically significant，通常已經不是單純 visualization，而是在問統計分析。

NormalizationAugmentationPCA→Regression Analysis→Accuracy / Training Time
TechniqueAccuracy effectp-value直覺
Normalization+2%0.03若門檻為 0.05，可視為顯著
Augmentation+5%0.002顯著，且效果較大
PCA-1%0.48不足以判定顯著

t-test

典型用途：比較兩組平均值。

例：有 Normalization vs 沒有 Normalization。

ANOVA

典型用途：比較三組以上平均值。

例：Normalization、PCA、Augmentation 三組。

考試版：兩組平均值 → t-test；3+ 組平均值 → ANOVA；很多因素 X、想知道誰影響 Y → Regression Analysis。

6. Multiple vs Multivariate Regression

名稱「多」的是什麼？例子
Multiple Regression多個輸入 XNormalization + PCA + Augmentation → Accuracy
Multivariate Regression多個輸出 YPreprocessing → Accuracy + Training Time
題庫用語不一定每次都非常嚴格。作答時先抓真正意圖：是否要分析多個 preprocessing factors 對 Accuracy / Training Time 的影響，而不是只因一個術語卡住。

9. 5 題自我測驗

Q1. 預測 GPU 溫度 67.3°C，是 Regression 還是 Classification？
看答案

Regression。輸出是連續數值。

Q2. 判斷 GPU 是否 Fault，最可能使用 MAE 還是 F1？
看答案

F1。Fault / Normal 是分類。

Q3. 想找 Accuracy 分布與 outlier，使用 Heatmap 還是 Box Plot？
看答案

Box Plot。

Q4. 比較 Normalization 與 No Normalization 兩組平均 Accuracy 是否有顯著差異？
看答案

t-test。典型兩組平均值比較。

Q5. Normalization、PCA、Augmentation 哪些對 Accuracy 與 Training Time 有顯著影響？
看答案

Regression / multivariate regression analysis。重點是估計多個因素對結果的影響，而不是只畫圖。
