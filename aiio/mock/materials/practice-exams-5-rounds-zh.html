五回合模擬題 — 第一回合：AI 算力基礎與基礎設施（Round 1）

R1-Q1 1. 在微架構設計上，GPU 採用 SIMT (Single Instruction, Multiple Threads) 架構，這與傳統 CPU 的主要差異為何？
  • A. GPU 透過少數高時脈核心極致降低單一執行緒延遲
  • B. GPU 著重於將晶片面積分配給龐大的 Cache 與分支預測器
  • C. GPU 透過數千個 Stream Processors 同時執行相同指令於不同資料集，提升總體吞吐量
  • D. GPU 不支援任何矩陣運算
查看答案與深度解析
正確答案：C
【解析】：SIMT (單指令多執行緒) 是 GPU 平行計算的核心，適合處理大量無相依性的資料平行任務（高吞吐量），而 CPU 則專注於低延遲與複雜順序邏輯。
R1-Q2 2. NVIDIA Hopper 架構導入的 FP8 精度中，E4M3 格式最適合應用於下列哪一個情境？
  • A. Backward Pass 中的梯度 (Gradients) 傳播
  • B. Forward Pass 中的權重 (Weights) 與激活值 (Activations)
  • C. 遠端儲存設備的備份壓縮
  • D. 網路封包傳輸標頭
查看答案與深度解析
正確答案：B
【解析】：E4M3 (1 Sign, 4 Exponent, 3 Mantissa) 具有較高的 Mantissa 精度，非常適合用於前向傳播的權重與激活值；而 E5M2 (5-bit Exponent) 具備較高動態範圍，適合梯度。
R1-Q3 3. TensorRT 推理優化中的 Layer Fusion（層融合）技術，主要如何提升模型推斷效率？

  • B. 將連續運算層（如 Conv + Bias + ReLU）合併為單一 CUDA Kernel，減少 GPU Global Memory 讀寫次數

  • D. 自動將輸入圖片尺寸裁切為一半
查看答案與深度解析
正確答案：B
【解析】：Layer Fusion 能減少 GPU DRAM (Global Memory) 與 Register 間的頻寬消耗（Memory Bandwidth Bound 瓶頸），並降低 Kernel Launch 開銷。
R1-Q4 4. GPUDirect Storage (GDS) 技術能夠大幅降低 I/O 延遲，其最關鍵的傳輸路徑改變為何？
  • A. 將資料先壓縮後再寫入 NVMe SSD
  • B. 繞過 Host CPU System Memory，直接建立 NVMe SSD 到 GPU VRAM 的 PCIe Direct DMA 通道

R1-Q7 7. 相較於 FP16，BF16 (Bfloat16) 為何在深度學習大模型訓練中更受青睞？
  • A. 因為 BF16 佔用的顯存比 FP16 少一半
  • B. 因為 BF16 保留了與 FP32 相同的 8-bit 指數 (Exponent) 動態範圍，能有效防止梯度下溢
  • C. 因為 BF16 運算速度慢但精度高
  • D. 因為 BF16 不需要 GPU 硬體支援
查看答案與深度解析
正確答案：B
【解析】：BF16 (1 Sign + 8 Exponent + 7 Mantissa) 與 FP32 具備相同動態範圍，能避免 FP16 容易發生的 Underflow，且計算吞吐量與 FP16 相當。

R2-Q1 1. 深度學習模型訓練 (Training) 期間，顯存 (VRAM) 佔用量高於推理 (Inference) 的關鍵原因為何？
  • A. 訓練階段需要額外儲存中間層 Activation Tensors 以供反向傳播計算梯度
  • B. 訓練階段的模型權重比推理階段大 10 倍
  • C. 推理階段不需要載入任何權重
  • D. 訓練階段只能使用 FP64 雙精度
查看答案與深度解析
正確答案：A
【解析】：訓練時的反向傳播 (Backward Pass) 必須利用前向傳播保存的中間 Activation 來計算 Gradient，因此顯存消耗遠大於僅執行前向傳播的推理。

查看答案與深度解析
正確答案：B
【解析】：Entropy Calibration 透過代表性數據觀察動態範圍，利用 KL 散度 (Kullback-Leibler Divergence) 找尋最佳飽和門檻值 (Threshold)，將 FP32 映射至 INT8。

五回合模擬題 — 第三回合：進階算力架構與併發優化（Round 3）

R3-Q1 1. 高階 GPU (如 H100) 採用的 HBM3 記憶體與傳統 DDR5 相比，最顯著的優勢是什麼？

R3-Q2 2. 在某張 GPU 上編譯完成的 TensorRT `.engine` 檔案，是否可以直接複製到另一種微架構的 GPU (例如 A100 -> H100) 執行？
  • A. 可以，只要 CUDA 版本相同即可
  • B. 否，TensorRT Engine 包含特定 GPU 架構最佳化的 CUDA 組合語言，具備硬體專屬性
  • C. 可以，TensorRT 具備跨平台的完全攜帶性

【解析】：TensorRT 針對當前編譯目標 GPU 的 Compute Capability 和硬體單元進行 Kernel 編譯與 Auto-tuning，因此 Engine 無法跨不同 GPU 微架構直接復用。

R3-Q5 5. LoRA (Low-Rank Adaptation) 大模型高效微調技術的核心數學邏輯為何？
  • A. 刪除神經網絡中 90% 的層
  • B. 凍結原始權重 $W_0$，透過相乘兩個低秩矩陣 $A \times B$ 擬合權重更新量 $\Delta W$
  • C. 將所有浮點數轉換為 1-bit
  • D. 將模型的 Attention Head 數量減半
查看答案與深度解析
正確答案：B
【解析】：LoRA 凍結 $W_0 (d \times k)$，加入低秩矩陣 $A (d \times r)$ 與 $B (r \times k)$，其中 $r \ll \min(d, k)$，大幅減少需可訓練參數量。
R3-Q6 6. 在超大規模 LLM 訓練或推理中，Tensor Parallelism (張量平行) 的主要切割對象為何？

【解析】：Tensor Parallelism (如 Megatron-LM) 將單一矩陣運算內部的 Column/Row 拆至多張 GPU，依賴 NVLink 的超高頻寬做 Intra-node 通訊。
