最容易忽略：不要把題目唸出來。Certiverse 的監考規則將 looking off screen、mumbling / speaking aloud、離開 webcam 畫面等列為可能被調查的行為。英文題目再難，也盡量在心裡讀。

1. 證件

  • First Name / Last Name 必須與註冊姓名一致。
  • 使用有效、未過期的實體政府核發照片證件。
  • 最省事的做法：註冊英文姓名直接照護照。

2. 電腦

  • Windows 11 或更新版本。
  • macOS Sonoma 14 或更新版本。
  • Live / AI proctoring 不支援 Chromebook、iPhone/iPad、Android。

3. 瀏覽器 / SEB

  • Chrome 或 Edge 最新版。
  • 只有當考試邀請或指示明確要求時才需要 Safe Exam Browser (SEB)。
  • 若需要 SEB，務必考前先安裝、再跑相容性測試。

4. Webcam / Mic / 網路

  • Webcam 必須正常。
  • 使用內建麥克風；headset microphone 不允許。
  • 最低下載 5 Mbps、上傳 5 Mbps。

5. 公司電腦不是首選

  • 可能被 admin 權限、資安軟體、VPN、remote access 工具干擾。
  • 若有私人 Windows 11 / Mac，通常比公司管控電腦單純。

6. 桌面與房間

  • 私人、安靜、光線足夠的空間。
  • 書、紙、筆記、手機、平板、智慧手錶等移走或關閉。
  • 只能使用一組 mouse、keyboard、monitor/display。
7. 不要最後一刻才測。Certiverse 官方把 System Compatibility Check 特別標成 CRUCIAL。考試前幾天先完成 webcam、mic、network 與 SEB（若需要）檢查。

改期、取消與 No-show

情況目前 Certiverse 規則你應該怎麼做
距考試 ≥ 24 小時可透過 Certiverse 自行 reschedule；Certiverse 不收改期費。不要拖，確定時間不行就立即改。
距考試 < 24 小時不能自行 reschedule；需聯絡 Certiverse support 取消 reservation。盡快聯絡 support，不要直接 no-show。
新的考試日期不能超過 original booking date 60 天。改期時同時檢查 60-day window。
No-show考試費通常不退；需要重新預約，通常代表重新付款。即使有突發狀況，也要主動聯絡 support。
記法：「24 小時」是改期門檻；「60 天」是可移動的最遠範圍。
