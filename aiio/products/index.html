最容易混：TensorRT、Triton、NIM、Dynamo 到底差在哪？

把它們放進同一條 inference pipeline 就清楚了。它們不是互斥產品，而是解決不同層級的問題。

Training 完的 ModelPyTorch / ONNX / LLM
TensorRTOptimize model execution
TritonServe models via inference server
NIMPrebuilt optimized microservice
DynamoScale distributed GenAI inference
模型最佳化 → 模型服務 → 微服務化 → 大規模分散式 serving
產品最簡單的一句話最常見考題字眼不要誤認成
TensorRT讓 inference 執行更快optimization, low latency, engine, precisionTriton server
Triton把模型 serve 給 clientinference server, dynamic batching, HTTP/gRPC模型訓練 framework
NIM封裝好的 production AI microservicemicroservice, API, fast deployment單純 optimizer
Dynamo大型分散式 GenAI inference orchestrationKV cache, distributed serving, prefill/decode單機 TensorRT
考試口訣： TensorRT = 加速；Triton = 服務；NIM = 包好可部署；Dynamo = 大規模分散式推論。

最常搞混的配對

Isaac vs Jetson
Isaac = robotics software / development platform；Jetson = edge AI compute platform。
Clara vs TensorRT
Clara = healthcare-specific；TensorRT = 通用 inference optimization，醫療也能用但不是 healthcare 專屬。
Metropolis vs Jetson
Metropolis = vision AI application platform；Jetson = 執行 edge AI 的硬體 / compute 平台。
TensorRT vs Triton
TensorRT = optimize model；Triton = serve model。
Omniverse vs Isaac
Omniverse = general 3D / digital twin / physical simulation foundation；Isaac = robotics-specific development stack，兩者可一起使用。
Merlin vs RAPIDS / CUDA-X
Merlin = recommendation-specific；CUDA-X Data Science = 通用 GPU data science / analytics。
DGX vs HGX
DGX = NVIDIA 完整 system；HGX = 給 server makers 整合的 platform / building block。
GPU Operator vs DCGM
GPU Operator = Kubernetes GPU software lifecycle；DCGM = GPU monitoring / health / diagnostics。
