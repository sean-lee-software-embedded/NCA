兩日讀書計畫

每完成一個時段，就用該章的 Check 題確認概念。

  1. 週六 09:00–12:00

    AI 基礎與加速運算
    Ch. 1–3：AI / ML / DL、Training / Inference、CPU 與 GPU。

  2. 週六 13:00–17:00

    NVIDIA 軟硬體堆疊
    Ch. 4–7：CUDA、NCCL、TensorRT、GPU 架構與 NVIDIA 平台。

  3. 週六 20:00–21:30

    第一輪複習
    不重讀全文，只整理答錯的 Check 題與容易混淆的元件配對。

  4. 週日 09:00–12:00

    資料中心基礎設施
    Ch. 8–10：網路、儲存、電力與散熱。

  5. 週日 13:00–16:00

    部署與維運
    Ch. 11–14：Kubernetes、GPU Operator、Monitoring、BMC 與情境題。

  6. 週日 16:15–18:00

    50 題模擬考
    限時作答、訂正錯題，再回完整教材補讀對應章節。

答題原則：先完成定義題與直接配對題；情境題先找題目真正要改善的指標，再選最直接負責的元件。
