iThome 攻略保留的 6 個高價值原則

  1. 先學範圍，再大量 hands-on。
  2. 刷題時就只靠官方文件，練搜尋關鍵字與 Ctrl+F。
  3. 善用 -h、kubectl explain、--dry-run=client -o yaml。
  4. 每題第一件事確認 host / context / namespace。
  5. 卡題時間盒；先拿高把握分數再回頭。
  6. Killer.sh/模擬環境要用 2 小時計時，考速度與 verification。

Readiness Gate｜比 66% 拉高安全邊際

  1. 100/100頁完成一次；Troubleshooting 30頁至少兩輪。
  2. 隨機抽20頁、不看 Command Path，至少17頁能完成＋驗證。
  3. 真 Linux 完成 kubeadm lifecycle/upgrade、Node NotReady+kubelet、static control-plane/crictl。
  4. 兩次不同的2小時模考都 ≥85%，任何 domain ≥75%。
  5. 每次至少保留15–20分鐘檢查。
