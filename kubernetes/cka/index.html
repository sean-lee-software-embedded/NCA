02 · Mac mini Setup

Docker Desktop + kind：先把可重建環境固定

建議：Docker Desktop 分配約 6-8 GB RAM。Apple Silicon / Intel 都可使用 kind multi-arch images。kind 很適合 RBAC、workload、service、storage 與大部分 troubleshooting；真正 kubeadm/systemd/etcd disaster recovery 再用 Linux VM / Killer.sh 補。
brew install kubectl kind helm
uname -m

cat > kind.yaml <<'EOF'
kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4
nodes:
- role: control-plane
- role: worker
- role: worker
EOF

kind create cluster --name cka --image kindest/node:v1.35.8@sha256:07b2536e30b803ed61d1677a79df6115f798ce64c80f9e22f6ed45afd09323c0 --config kind.yaml
kubectl get nodes -o wide
