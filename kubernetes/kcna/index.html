00 · How to Learn

每一頁要做到「會解釋、會驗證、會判斷」才算讀完

1. 先懂用生活化比喻建立心智模型
2. 再精準知道正式定義與責任邊界
3. 動手驗證Mac mini 跑 command 看真實輸出
4. 換句話考用情境題確認不是死背
已修正原本的 Q2 問題：舊版大量出現同一句「看到相關故障時，最好的第一步是？」；新版不再顯示那組模板題，而是依主題產生不同情境。例如 scheduler 會問 FailedScheduling、RBAC 會問 auth can-i、PVC 會問 Pending、Readiness 會問 Running 但不接流量。
